# セマンティックバージョン範囲解決 npm互換チェッカー

semver範囲式（^1.2.3 / ~2.0.0 / >=1.0.0 <2.0.0 等）の意味を自然言語で解説し、バージョン一覧から満足するものを色分け判定するツール。
semver.js相当のparser（外部ライブラリ不使用・完全JS実装）により、キャレット・チルダ・比較演算子・OR範囲を解析する。
2つの範囲式を入力すると共通範囲（衝突検出）を自動計算。npm / Cargo / RubyGems の範囲記法差異を比較表で確認できる。
プリセット範囲式をワンクリックで挿入可能。

## 使い方

1. 範囲式1欄に semver 範囲式を入力する（例: ^1.2.3）
2. バージョン一覧テキストエリアに1行1バージョンで入力すると満足/不満足が色分け表示される
3. 範囲式2を入力すると2つの範囲の共通集合（衝突検出）が表示される
